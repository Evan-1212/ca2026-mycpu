# What This Repository Uses from chisel-bootcamp

The tasks are built on the student's own chisel-bootcamp Module 5 code: the sbt project
`bootcamp` compiles `$BOOTCAMP_DIR/riscv/src/main/scala` (package `riscv`), and the code of this
repository (package `mycpu.*`) refers to it by name. This file lists every name it refers to.

## Rules

- **The bootcamp is never changed for this repository.** A rename, a removal or a changed
  signature of a symbol in the table below breaks this repository. Such a change in the bootcamp
  needs a new pin here (`BOOTCAMP_COMMIT` in the top-level `Makefile`) and the matching change in
  the sources.
- Symbols are imported by name (`import riscv.{Alu, AluOp}`) or written with the package
  (`riscv.Ram`). `import riscv._` is refused, because it hides what is used.
- `riscv.Programs` is not used: it reads `programs/src` relative to the working directory, and
  the specs of this repository run with one working directory per task.
- Seven of the bootcamp's files are exercises (`Alu`, `DecodeRows`, `BranchUnit`, `LoadExtend`,
  `PipelineFlush`, `Forward`, `UartTx`). `make check-bootcamp` requires all seven to be finished,
  whether or not the table below names them (`Forward` and `PipelineFlush` are for T4).

## How the table is kept current

The reference repository of the course generates the table, from the Scala sources that git
tracks with their comments and string literals removed; these two targets are not in your tree:

```shell
make bootcamp-interface         # rewrite the table below
make check-bootcamp-interface   # fail when the table differs from what the sources use
```

Both run `scripts/bootcamp-symbols.py`, which also fails when a symbol is not defined at the top
level of a file of the bootcamp clone, so a symbol that the bootcamp renamed or removed is
reported here by file and line. The two targets and the script exist in the reference
repository only, whose CI runs the check; the public tree has the generated table. "Used in"
names the top-level directory of the using files, and whether they are main or test sources.
